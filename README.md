# LHPet

Projeto desenvolvido utilizando **ASP.NET Core MVC**.

## Tecnologias

- .NET 10
- ASP.NET Core MVC
- C#

## Como executar o projeto

Clone o repositório:

```bash
git clone URL_DO_REPOSITORIO
```

Entre na pasta do projeto:

```bash
cd LHPet
```

Restaure as dependências:

```bash
dotnet restore
```

Execute a aplicação:

```bash
dotnet run
```

Acesse no navegador o endereço informado pelo terminal.

## Estrutura

- **Controllers** → regras de controle da aplicação
- **Models** → modelos de dados
- **Views** → telas da aplicação
